# Nuri 한국어 문서

이 폴더는 `docs/`의 지속적으로 유지되는 영어 기준 문서에 대응하는 한국어 번역입니다. 구현과 설계의 최종 기준은 영어 문서이며 의미가 다르면 영어 문서를 우선합니다.

## 문서 지도

| 영어 기준 문서 | 한국어 번역 |
|---|---|
| `docs/architecture/RUNTIME_ARCHITECTURE.md` | [RUNTIME_ARCHITECTURE.md](architecture/RUNTIME_ARCHITECTURE.md) |
| `docs/architecture/RUNTIME_IDENTITY.md` | [RUNTIME_IDENTITY.md](architecture/RUNTIME_IDENTITY.md) |
| `docs/architecture/LIFECYCLE.md` | [LIFECYCLE.md](architecture/LIFECYCLE.md) |
| `docs/renderers/README.md` | [Renderer 계약](renderers/README.md) |
| `docs/performance/DUXEL_PERFORMANCE_ANALYSIS.md` | [DUXEL_PERFORMANCE_ANALYSIS.md](performance/DUXEL_PERFORMANCE_ANALYSIS.md) |
| `docs/guides/FORMATTING.md` | [FORMATTING.md](guides/FORMATTING.md) |

지속적으로 유지하는 영어 기준 문서를 변경할 때는 같은 작업에서 동일한 하위 경로의 한국어 번역도 수정합니다. Code symbol, path, command, API name, package version 및 측정값은 영어 문서와 동일하게 유지합니다.

`docs/operations/`의 운영 기록은 전체 번역 대상이 아닙니다. 운영 기록에 장기적으로 유지할 결정이 생기면 영어 및 한국어 기준 문서 쌍으로 옮깁니다.
